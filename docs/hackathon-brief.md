# Lablab x AMD AI Academy Challenge — Hackathon Brief

Source: https://lablab.ai/ai-hackathons/amd-lablab-ai-academy-challenge (fetched 2026-09-10 via Playwright, all accordions/FAQ expanded)

## TL;DR

This is **not a weekend hackathon** — it's a 3-month, ongoing, **individual-only** developer growth/points program run by lablab.ai + AMD + NativelyAI. You earn XP continuously (learning courses, bi-weekly mini-challenges, blogging, referrals, Discord help) that builds toward rank badges and a shot at 3 cash prizes for whoever reaches the top rank ("Legend") first. There's a live submission deadline shown as **Dec 2, 12:30 AM IST**, but XP accrual and leaderboard climbing start the moment you join.

## What It Actually Is

A guided, self-paced learning + building journey using the **AMD AI Academy** learning pathway, with a **new mini-challenge roughly every two weeks**. Per the page, the six challenge themes planned across the 3 months are:

1. AMD AI Academy learning pathway — model serving, MCP, agents & tool calling, GPU resource consumption.
2. Optical Character Recognition (OCR) — prompting and serving a multi-modal model.
3. RAG (Retrieval-Augmented Generation) — improving accuracy / reducing hallucination on proprietary domain knowledge.
4. Web-scraping agent — retrieves requested info (phone numbers, software versions, etc.).
5. Multi-agent software engineering solution.
6. Teach a system to play a novel game, combining learnings from challenges 1–5 plus model fine-tuning.

Note: as of the fetch, only **Month 1** content is published in detail ("Get Started With AMD" — onboarding, no building required). Months 2 and 3 themes are marked **TBA** in the page's hidden/commented content, and an "Infrastructure" section is literally labeled **"Info coming soon."** So the roadmap above is directional, not finalized.

### Month 1 — "Get Started With AMD" (onboarding & learning, no project required)
1. Connect your AMD Developer account (so activity is tracked).
2. Claim your AMD Developer Cloud credits.
3. Complete an introductory AMD tutorial / AI Academy module.
4. Optional: run your first AMD workload (head start on Month 2).

Completion is auto-verified from AMD activity — no repo or demo needed this month, and there's no judging/ranking on speed for Month 1.

## What Participants Get

- **$100 AMD Developer Cloud GPU credits** — new AMD AI Developer Program sign-ups only.
- **AMD AI Academy** — courses, technical resources, tutorials, documentation.
- **1 month DeepLearning.AI Pro** — new sign-ups only.
- **Expert & community access** — AMD engineers, private channels, office hours, early access to AMD dev events.
- **Project recognition** — potential showcase on AMD social channels / at AMD developer events.
- AMD **Certificate of Completion** for those who complete the challenge.

## How To Join

Click **"Sign Up with AMD"** on the event page. If you're not already in the AMD AI Developer Program you'll be prompted to create an account there too. Also: Join the lablab Discord (https://discord.com/invite/lablabai) and the AMD Discord (https://discord.com/invite/pxgGQHeVjg).

You can join **at any point** during the 3 months and start earning XP immediately — no need to have completed earlier monthly challenges to take part in later ones.

## Ways To Earn XP

XP accrual starts day one, independent of whether a monthly build-challenge has dropped yet.

**Onboarding**
- Create AMD Developer account — Required
- Connect your lablab account — Required
- Join the Discord — +50 XP
- Complete your AMD profile — +100 XP

**Learning**
- Complete an AMD Academy course — +150 XP
- 5-course AI Academy bonus — +100 XP
- 10-course AI Academy bonus — +100 XP
- Complete ROCm Certification — +150 XP

**Building** (highest-weighted category — "what the Challenge is really for")
- Create your first project — +50 XP
- Connect your GitHub repo — +5 XP
- Submit a project demo — +150 XP
- Submit a complete project — +200 XP
- Submit an open-source project — +200 XP
- Participate in an AMD hackathon — +300 XP
- Build using AMD technologies — +250 XP
- Reach a project milestone — +100 XP (capped at 3 milestones per project)

**Community Support** (page states this "counts as much as building yourself")
- Answer a Discord question — +5 XP
- Get a "like" from another user — +2 XP
- Have your solution accepted — +50 XP
- Earn the Community Contributor badge — +250 XP

**More TBA** — page says additional XP sources will be revealed later.

**Referrals** — live from day one, no need to wait for a monthly challenge:
1. Get approved (sign up, wait for enrollment approval).
2. Generate your referral link from your dashboard.
3. Share & track referral activity from the dashboard.

## Rewards / Ranking

Two reward types:
1. **Rank badges** (climbed via XP): Bronze → Silver → Gold → Platinum — each grants badges, Discord roles, and extra AMD credits.
2. **Cash prizes — Legend rank only**: Reaching "Legend" requires XP **plus** completing a final challenge that only unlocks near the end of the program, so winners are decided in the closing weeks, not early. First 3 people to reach Legend win cash:
   - 1st to reach Legend — **$2,500**
   - 2nd to reach Legend — **$1,500**
   - 3rd to reach Legend — **$1,000**
   (Total = $5,000 prize pool, matches the stated pool.)

XP alone does **not** decide the cash winners — it's a race to complete the gated final challenge.

## Tracking Progress

- Points update **every Friday**, reflecting activity through the previous Wednesday (not real-time).

## FAQ (from the page, expanded)

- **Do I need to join at the start?** No — join anytime, earn XP immediately, no need to have done earlier monthly challenges.
- **Does previous AMD hackathon participation count?** No — only activity after joining counts toward XP/ranking. Past AMD event history may still show on your profile but doesn't affect this event's score.
- **Do I need AMD hardware?** No — every challenge has a cloud path via AMD Developer Cloud; local AMD hardware is optional.
- **Does XP alone decide Legend cash prize winners?** No — need XP **plus** completing the late-unlocking final challenge; first 3 to reach Legend win.
- **Can I work in a team?** No — individual participation only; every builder earns XP on their own account.

## Strategic Notes (for deciding whether/how to compete)

- This is a **marathon, not a sprint** — earliest, cheapest points come from onboarding + learning + community actions, not building. If low-effort/high-certainty XP matters, prioritize: create AMD account, connect lablab account, join Discord (+50), complete AMD profile (+100), then AMD Academy courses (+150 each, +100 bonus at 5 and 10 courses), ROCm Certification (+150).
- **Building** is the highest-weighted category (submitting a complete/open-source project = +200 XP each, using AMD tech = +250 XP, hackathon participation = +300 XP) — but the cash prizes don't come from XP volume alone; they come from being among the **first 3** to clear a late-unlocking "final challenge" gate. That means pure grinding won't guarantee a cash prize — timing and readiness for the final gate matters more once it unlocks.
- Community-support XP (Discord answers, likes, accepted solutions, Community Contributor badge) is explicitly said to "count as much as building" — a viable low-code path to rank up without heavy engineering effort, if cash prizes aren't the target and just the badges/credits are.
- Because no team competition exists here, this doesn't fit the multi-person team hackathon model tracked for other events in memory — it's a personal/ongoing engagement, not a single build-and-submit sprint.
